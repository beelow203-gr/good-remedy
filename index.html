Common questions

What buyers usually ask first.

Is Good Remedy a software platform or a consulting service?

It is a software platform delivered through a managed implementation. The first operation is built closely with the client. The ongoing relationship can include the dedicated environment, software, support, and managed operation.

Is Good Remedy a public self service app?

No. Good Remedy is currently delivered as a private client environment around a specific operation.

Does Good Remedy replace our existing AI tools?

Usually no. Good Remedy works around the operation and uses the tools that fit.

Do we need live system access for the first conversation?

No. A sanitized example is enough to see whether there is a useful place to start.

What is a good first operation?

One that repeats, matters, and still depends on one experienced person to remember everything.
